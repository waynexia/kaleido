# 行为基线

采样日期：2026-10-11。参照本机已安装的 AltTab 7.21.1，通过偏好设置界面与偏好键核对。没有修改 AltTab 配置。

## AltTab 参照配置（采样快照）

| 项目 | 值 |
| --- | --- |
| 主快捷键 | Control + Tab；松开 Control 聚焦选中窗口 |
| 同应用窗口 | Option + Tab 上方的键（美式键盘为反引号） |
| 顺序 | 最近聚焦优先，首次选择下一个窗口 |
| 范围 | 所有应用、桌面、屏幕 |
| 窗口状态 | 包含最小化、隐藏和全屏窗口 |
| 切换器 | 标题样式、中等尺寸、系统主题、正常可见性 |
| 屏幕 | 鼠标所在屏幕 |
| 出现延迟 | 100 ms |
| 动画 | 关闭时淡出 |
| 列表内容 | 应用图标、窗口标题、状态标记、应用通知标识 |
| 隐藏内容 | 桌面编号、无窗口应用、缩略图 |
| 控制 | Shift 反向、方向键、Space 聚焦、Esc 取消；W 关闭、M 最小化、F 全屏、Q 退出、H 隐藏 |
| 其他 | 菜单栏图标隐藏；可登录启动 |

未启用：第三快捷键、手势、Vim 导航、悬停即选择、鼠标跟随焦点、选中窗口预览、标准标签页独立展示。

## Kaleido 当前行为与差异

Kaleido 的标准方案使用上述原始快捷键，全新安装默认选择标准方案，之后保留用户已选方案。本机为保留 AltTab 并排验收，已选用共存方案：Control + Option + K 切换所有窗口，Control + Option + J 切换当前应用窗口。标准方案在 AltTab 运行时待命，共存方案可同时使用；不会修改 AltTab 原配置。

Kaleido 默认显示菜单栏图标，点击直接打开设置；仍可在设置中隐藏，已有可见性偏好优先。关闭设置不会退出后台进程，再次打开应用可回到设置。暂停快捷键仅在本次运行生效，登录启动需用户自行启用。

窗口范围、顺序、动作与面板外观按上述基线实现。窗口枚举排除 Kaleido 自身、禁止激活的进程和 `com.McAfee.McAfeeSafariHost`；远程桌面/虚拟机的快捷键让行规则见[架构说明](architecture.md)。当前实现与实机覆盖并不等同，已验证项目和剩余限制见[验证记录](validation.md)。

## 外观参数

标题样式使用 26 pt 应用图标、14 pt 系统字体、7 pt 行内边距、18 pt 面板边距、10 pt 行圆角和 23 pt 面板圆角。浅色为半透明浅背景与灰色选中行，深色跟随系统。使用原生毛玻璃材质。窗口名称尾部截断；内容过长时滚动。

旧版遗留的 `maxWidthOnScreen=50` 等键不直接代表 7.21.1 当前标题样式的实际布局；以该版本生效的样式和界面为准。

标题列表宽度随屏幕尺寸固定，不随标题长度变化。实机在 1512 × 982 点屏幕上核对长列表，两者面板均为 820 × 786 点；最大高度以完整屏幕尺寸计算。行高 40 pt，行间距 1 pt，应用图标与标题间距 2 pt，通知角标位于图标右上方。
