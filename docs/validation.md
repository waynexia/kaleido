## 复现

先退出正在运行的 Kaleido 和旧 Window Fixture，保留 AltTab。构建后确认当前 `build/Kaleido.app` 的辅助功能授权有效，再运行：

```sh
./scripts/fixture.sh
open build/Kaleido.app --args --coexist --integration-check "$PWD/build/integration-report.json"
```

这是显式启用的 Debug 集成测试，会短暂发送全局按键并改变测试窗口。运行期间不要同时操作键盘。成功后退出测试应用，Kaleido 继续后台运行。报告的 `status` 为 `passed` 或 `failed`；测试不会修改 AltTab 配置。

添加 `--capture-kaleido` 或 `--capture-reference` 可让驱动分别在面板可见时暂停最多 45 秒。报告状态为 `kaleido-visible` 或 `reference-visible`，检查完后创建 `<报告路径>.kaleido-continue` 或 `<报告路径>.continue` 继续；再次使用前删除旧的继续标记。

ad-hoc 签名在构建变化后可能失效。必要时从辅助功能列表移除旧条目，添加当前应用并重启。通过 `open` / LaunchServices 启动；直接运行可执行文件的 `--diagnose` 仅描述该命令进程的权限上下文，不能代表已启动的应用。

## 仍需扩展覆盖

- 任意多桌面往返、多显示器间移动鼠标后的面板定位，以及各第三方应用的 AX 差异；本次全屏测试不等同于覆盖全部 Space 情况。
- 鼠标点击行、悬停按钮和减少动态效果的完整交互回归；本轮实机动作主要通过键盘验收。
- 登录项注册与实际重新登录、Developer ID 签名与公证。
- 不宣称逐像素一致：系统材质、滚动条显隐、图标来源和不同系统版本的渲染可能有细微差异。
