## 授权后的验收步骤

1. 为最终固定路径的 `Kaleido.app` 开启辅助功能。确认设置显示“已就绪”；AltTab 需先退出。
2. 运行 `./scripts/fixture.sh`。仅使用这三个可丢弃窗口测试 W / M / F / Q / H，避免影响真实文档。
3. 依次前置 One、Two、Three，核对 MRU、反向循环、方向键、Space 和 Esc。快速按下并释放 Control + Tab，确认窗口切换且浮层不闪烁。
4. 最小化或隐藏测试窗口，确认列表保留状态标记，释放 Control 可以恢复并前置该窗口。
5. 在测试应用中关闭当前选中窗口，确认选择移到相邻项；关闭全部测试窗口，确认应用不出现空占位项。
6. 将测试窗口移动到其他桌面/屏幕，并进入原生全屏，核对跨桌面切换和面板位置。
7. 连续快速重开切换器，核对 120 ms 淡出不会隐藏新一轮面板。检查减少动态效果和深色外观。
8. 退出测试应用。需要恢复原环境时退出 Kaleido，重新打开 AltTab；其原始配置未被修改。

构建使用本地 ad-hoc 签名，重新构建可能导致 macOS 要求重新授权。发布前还需要 Developer ID 签名、公证和上述系统集成验收。
