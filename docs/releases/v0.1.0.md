# Kaleido v0.1.0

首个版本：原生 Swift + AppKit macOS 窗口切换器。

## 功能

- Control + Tab 切换所有窗口，Option + 反引号切换当前应用窗口；松开修饰键聚焦，支持反向选择、方向键、取消和窗口操作。
- 最近聚焦优先，包含最小化、隐藏和全屏窗口；标题列表跟随系统主题，在鼠标所在屏幕显示。
- 菜单栏设置入口、可保存的快捷键方案、登录启动选项，以及缺少辅助功能权限时的自动引导。
- 窗口标题和切换历史仅驻留内存，无需屏幕录制权限。

## 下载与安装

- `Kaleido-v0.1.0-macos-universal.zip`：Release 优化构建，包含 arm64 和 x86_64，最低 macOS 13。
- `SHA256SUMS.txt`：下载后在同一目录运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。
- 解压后将 `Kaleido.app` 放到固定位置（例如 `/Applications`），打开并在“系统设置 → 隐私与安全性 → 辅助功能”中允许 Kaleido。更新时先退出旧进程，并保留原安装位置。

**此版本使用 `Kaleido Local Development` 自签名证书，未使用 Developer ID，未经过 Apple 公证。** Gatekeeper 可能阻止首次打开；签名完整性验证不等同于 Apple 发行信任。此下载包不包含私钥或签名凭据。

## 验证与限制

- Apple Silicon / macOS 15：31 项 XCTest、应用包自检及签名连续性检查通过。本机 Release 构建经 LaunchServices 启动，仍显示“已就绪”及标准快捷键，无需重新授权。
- 通用二进制的双架构、最低系统版本、签名以及 ZIP 解压后的自检与 SHA-256 校验通过；Debug 全局集成驱动未编入 Release。
- Intel 实机运行、macOS 13/14 实机运行、全新机器上的下载与安装尚未验证。
- 多显示器、多桌面、不同第三方应用的辅助功能兼容性，以及实际登录启动仍需扩展验收。此前标准方案的 13 项 Window Fixture 实机检查已通过，本次发布未重新发送全局测试按键。

完整记录见仓库的 [验证记录](https://github.com/waynexia/kaleido/blob/v0.1.0/docs/validation.md)。
