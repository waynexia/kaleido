# 架构与开发约定

## 模块边界

`KaleidoCore` 不依赖 AppKit，负责窗口描述、内存 MRU 排序、切换会话、快捷键状态机、尺寸约束与权限检查生命周期。`PermissionMonitor` 接收权限查询和定时调度闭包，可在不修改系统权限的条件下测试授权前后的状态变化。XCTest 覆盖边界行为。

`Package.swift` 要求 Swift 6 工具链，当前使用 Swift 5 语言模式；尚未迁移到 Swift 6 严格并发模式。

`Kaleido` 是 AppKit 应用：

- `WindowRepository` 在串行工作队列中读取普通应用及辅助应用的标准窗口和对话框；AXObserver 及 NSWorkspace 通知驱动刷新，3 秒轮询兜底（允许 200 ms 合并唤醒），60 ms 合并通知。每个窗口的角色、标题及状态通过一次批量属性请求读取；失败时保留已知记录或字段。按 PID 缓存应用图标，进程退出时清理；稳定窗口 ID 直接查表，兼容回退只比较同进程窗口。Space 动画造成的不完整列表保留最多 1.5 秒并重试；明确的销毁通知和应用退出立即移除。
- `Accessibility` 集中封装 AX 读写。动态查找 `_AXUIElementGetWindow` 来关联 WindowServer 的稳定 ID；该非公开符号不可用时退回 AX 对象比较。该兼容边界不用于执行窗口动作。
- `GlobalShortcuts` 在主 RunLoop 上用 CGEventTap 截获输入，调用纯状态机。事件回调不执行 AX 枚举或网络操作。会话期间以 25 ms 定时核对修饰键状态，防止遗漏松键通知后继续吞掉输入。事件 tap 被系统禁用时取消当前会话并重新启用。

- `SwitcherCoordinator` 管理缓存、100 ms 显示延迟、选择与聚焦。打开期间保持列表原顺序，标题/状态更新和窗口消失不会任意改变选择。
- `SwitcherPanelController` 使用非激活 NSPanel、NSVisualEffectView 与原生图标；跟随系统深浅色、减少动态效果设置，按鼠标所在屏幕定位。按窗口 ID 复用行，标题/状态更新不销毁控件或打断悬停。新会话和选择变化时滚入选中行；后台刷新保持用户手动滚动位置，不重复发送焦点通知。
- `AppDelegate` 管理单实例、权限与快捷键冲突状态、菜单栏按钮和设置入口。菜单栏图标默认显示，按钮直接打开设置；显式保存的可见性偏好优先于默认值。关闭设置不退出后台进程，再次打开应用可回到设置。
- `PreferencesWindowController` 提供权限入口、快捷键方案、暂停和菜单栏可见性开关，并通过 SMAppService 管理登录项。快捷键与菜单栏偏好持久保存，暂停只在当前进程内生效。

登录项的 `requiresApproval` 显示为已勾选、等待系统批准，用户仍可取消注册；重新激活设置时刷新系统状态。重复启动在应用命令行偏好前退出，避免新进程改变运行中实例尚未采用的方案。

快捷键状态机只在新的按键匹配启动组合时查询目标范围是否可用；普通输入、额外修饰键和自动重复不会触发前台应用查询。同应用范围为空时原样让行。取消或提交后，已经捕获的按键继续吞掉自动重复及配对的 key-up，直到松键；停止或重建 event tap 时清除旧捕获状态，避免影响后续输入。

`Accessibility` 在每次属性读取、写入、动作和 ID 桥接前，对实际 AX 对象设置 200 ms 消息超时。只设置应用根对象不会覆盖返回的窗口或子控件（[Apple API 语义](https://developer.apple.com/documentation/applicationservices/1459345-axuielementsetmessagingtimeout)）。批量属性中的 AXError / CFNull 作为缺失值处理，整批失败不视为空列表；显式空标题和 false 状态仍正常更新。原生边界测试通过注入批量响应验证，不访问真实窗口或修改权限。

## 权限和进程

仅需要辅助功能授权，不需要屏幕录制；不使用 AppleScript、截图、网络服务或私有窗口操作接口。窗口标题和 MRU 只驻留内存，诊断输出不包含标题。开发预览使用内置样本数据。

启动时由 `PermissionMonitor` 查询一次辅助功能权限。缺少权限时自动展示设置中的说明和系统设置入口，主 RunLoop 以 1.5 秒间隔等待授权；返回应用时可提前确认。授权成功后销毁定时器、隐藏入口并启动快捷键监听，不保留“重新检查”按钮。权限结果只保存在本次进程内存中，窗口仓库和启动协调器不再重复查询；下次启动重新检查。运行期间撤销权限不通过轮询探测，需要重新启动以更新权限状态。

AltTab 冲突通过 NSWorkspace 的应用启动、退出通知更新，不依赖权限定时器。打开设置、应用重新激活、切换快捷键或暂停状态时，使用已确认的权限结果更新运行状态并按需尝试启动监听。窗口列表自身的刷新定时器与授权检查相互独立。

快捷键方案保存在 Kaleido 自身偏好中。标准方案在 AltTab 运行时保持待命；共存方案使用 Control + Option + K / J，两者可同时工作。`--coexist` 可选中并保存共存方案。不会修改 AltTab 偏好、登录项或授权。

远程桌面/虚拟机快捷键让行依据 `SwitcherCoordinator.canBegin` 中的应用 ID 前缀与缓存的全屏状态；未逐一实测全部客户端。没有窗口的应用不创建占位项。支持标准窗口与对话框；不将非活动标准标签页单列为窗口。

## 限制与取舍

- 不同应用实现 AX 的质量不同；未暴露标准窗口、关闭按钮或全屏属性的应用无法保证相应动作成功。失败会发出系统提示音，不能强行绕过。
- 通过 AX 枚举所有应用，包含其他桌面的窗口；跨桌面/原生全屏的最终前置行为仍受 macOS 与目标应用影响，需要多显示器/多桌面人工验收。
- Dock 通知标识仅在其 AX 接口提供 `AXStatusLabel` 时读取；不会读取应用私有数据库来取得未公开计数。
- 窗口 ID 桥接为非公开兼容点，不承诺 Mac App Store 兼容性。替换此桥接不应影响 core 或 UI。
- Option + Tab 上方键按物理键码识别（美式布局为反引号）。快捷键以物理位置为准，不提供键盘布局编辑器。
- 使用仍受支持的 `hudWindow` 语义材质代替参考版本已废弃的 light/dark 材质；不同 macOS 版本、背景和辅助功能对比度设置下透明效果会略有差异。
- 登录启动已实现为系统登录项，但构建或首次运行不会自动注册；将应用放入固定位置后由用户启用。默认构建固定使用本地证书签名；更换签名身份可能需要重新授权，见[代码签名说明](code-signing.md)。

## 开发流程

1. 使用 `codex/` 或其他职责明确的分支。
2. 一次提交只承载一个完整变化，采用 `chore:`、`feat:`、`fix:`、`docs:` 等前缀。
3. 状态机变化补充行为测试；原生 UI 改动检查浅色、深色、长标题、滚动与键盘输入。
4. 代码或构建脚本变更运行 `make check`，包括签名连续性检查。构建会覆盖 `build/Kaleido.app`，先退出旧进程；实机验证通过 `open build/Kaleido.app` 启动。需要优化构建时运行 `CONFIGURATION=release make build`。
5. 更新行为基线、验证记录和已知限制。不提交构建产物、机器专属路径配置、真实窗口标题或完整用户偏好导出。

不将任务描述、实现目的、开发过程说明写入产品界面。UI 仅显示窗口内容、操作入口和必要的运行状态。

纯文档修改核对链接、路径、命令与代码一致性，并运行 `git diff --check`；无需重新构建或执行全局输入测试。验收记录描述实际完成的检查，不能由“已实现”推断“已实测”。

## 本地测试入口

```sh
./scripts/preview.sh        # 导出切换器及缺权/已就绪设置的浅色、深色预览
./scripts/fixture.sh        # 打开三个可安全关闭的测试窗口
build/Kaleido.app/Contents/MacOS/Kaleido --diagnose
```

预览 PNG 是 AppKit 视图的离屏绘制，用于尺寸与文字排版检查，不包含实际桌面毛玻璃取样。真实透明效果通过正常浮层人工检查。

`--preview --settings-preview` 显示固定的已就绪设置样本，加 `--missing-permission` 显示缺少权限样本。可配合 `--light` / `--dark` 和 `--export-preview <路径>` 导出；这些样本不启动权限监控或快捷键监听，也不修改系统授权。预览中登录项控制禁用，菜单栏开关仅改变样本，不写偏好；`--coexist` 在预览时不保存方案。缺权到授权的监控生命周期由注入状态的 XCTest 验证。

`IntegrationCheck` 是显式启用的 Debug 测试入口。它通过 CGEvent 发送真实全局按键，独立的 `FixtureAccessibility` actor 在后台查询测试窗口，避免阻塞主线程事件 tap。窗口管理动作限定在 `dev.waynexia.Kaleido.WindowFixture`；所有窗口范围只检查列表并取消。报告不含真实窗口标题，Release 不包含此入口。运行方法见验证记录。
